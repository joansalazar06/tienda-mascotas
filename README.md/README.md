# Elite Pets

Aplicación web para gestión veterinaria.

## Tecnologías
- HTML5, CSS3
- JavaScript
- LocalStorage
- Bootstrap

## Cómo Ejecutar
1. Clona el repositorio.
2. Abre `index.html` con Live Server o en el navegador.
